Why Dar es Salaam is hard to measure

Dar es Salaam has its own word for a traffic jam: foleni. Anyone who has sat on Morogoro Road in the early evening knows the city has them. What is missing is an open, continuous record: which roads, at which hours, how badly, and whether it is getting worse.

This project set out to build that record with nothing but free services, a scheduler and a database. The collector is the easy part. The feed is the hard part.

  • Commercial feeds stop short

    Live traffic products are built from phones and vehicles reporting their position. A provider can have the road map of a country without having the traffic layer for it. That is the case for TomTom in Tanzania.

  • Counts are surveys, not a series

    The University of Dar es Salaam, the World Bank and UN-Habitat have published traffic counts for the city. They describe the days they were taken. They do not run every half hour.

  • The budget is zero

    The pipeline runs on free tiers that cannot send a bill. When the alternatives were checked in September 2026, HERE and Google Routes both needed a payment card on file, so neither was adopted.

API

The pipeline, start to finish

One scheduled job, one request per monitoring point, one row per answer. There is no server to keep running.

  1. Scheduler

    GitHub Actions

    A cron entry asks for a run at 7 and 37 minutes past each hour. GitHub's scheduler is best-effort, so real gaps are longer.

  2. Collector

    main.py collect

    Loads the point list for the chosen city from config/cities/<city>.json and walks it.

  3. Provider

    TomTom Traffic Flow

    One request per coordinate. The answer is the nearest road segment's current speed, free-flow speed, confidence and closure flag.

  4. Parser

    parse_traffic_response

    Works out the congestion ratio, stamps the time in UTC and shapes the result into a row.

  5. Store

    Supabase Postgres

    The cycle's rows go in as one batch over the REST API, into a table called traffic_snapshots.

Slip road: a second workflow runs weekly. It pushes a heartbeat commit so GitHub does not switch the schedule off after 60 quiet days, re-enables the collector if it was disabled, and fails loudly if no rows have arrived recently.

How a monitoring point becomes a row

Every answer from the provider is stored as one row with these columns. This is the real schema.

ColumnTypeWhat it holds
idbigserialRow number
timestamptextWhen the reading was taken, ISO 8601, UTC
point_nametextThe monitoring point, named for its road
latituderealWhere the point is
longituderealWhere the point is
current_speedrealSpeed on the segment now, km/h
free_flow_speedrealSpeed on the same segment with no traffic, km/h
congestion_ratioreal0 to 1. How much of the free-flow speed has been lost
road_closureinteger1 if the provider reports the road closed, otherwise 0
confidencerealThe provider's own 0 to 1 confidence in the reading
created_attimestamptzWhen the database received the row

What the congestion ratio means

congestion_ratio = 1 − current_speed ÷ free_flow_speed

The result is held between 0 and 1. At 0 the road is moving as fast as it does when empty. At 0.5 traffic is at half that speed. Near 1 it is at a standstill. Dividing by each road's own free-flow speed is what lets a city street and a highway sit on the same scale.

How the 52 points were chosen

Coordinates typed by hand land in the wrong place, and the failure is silent. A traffic provider snaps any coordinate to its nearest road and returns a believable speed for it, so a point labelled for an arterial can spend months measuring a side street.

So the points are not typed. A generator builds them from OpenStreetMap road geometry, which means every coordinate is a node on the road it is named for.

The Dar es Salaam list holds 13 city-centre corridor points, 17 highway points and 22 main-road points.

  1. Ask for the roads

    Query Overpass for every named motorway, trunk, primary and secondary road inside the city's administrative boundary, plus the named streets of the centre.

  2. Group and measure

    Join the pieces of each road by name and measure its length inside the city.

  3. Rank under quotas

    Rank by road class, then length. Each class has a cap, so long trunk roads on the edge of the region cannot take every slot from the urban arterials.

  4. Sample along each corridor

    Place points from the middle of a road outwards, at least 0.5 km apart, or 0.3 km in the centre where blocks are short. Long arterials get several.

  5. Check every coordinate

    Reverse-geocode each point with Nominatim and re-sample any that come back on a different road. Where Nominatim has no name to offer, the point is kept and marked unverified.

What the data would let you do

A few weeks of half-hourly rows is enough to start asking questions that today get answered by anecdote. The two charts below use the same simulated day as the map.

  • Rush-hour profiles

    Average the ratio by hour of day and each road gets a signature: when its peak starts, how high it goes, how long it takes to clear.

  • Corridor comparison

    Put Morogoro, Bagamoyo, Nyerere, Kilwa and Nelson Mandela Road side by side and see which one fills first and which one stays full.

  • Rain effects

    Join each row to the rainfall in that hour and ask how much a downpour slows each road, and which roads it stops altogether.

Where it stands: diversion via Nairobi

TomTom has the road map of Dar es Salaam and no traffic data for it. Asked about any of the monitoring points, it gives the same reply:

Point too far from nearest existing segment.

The same collector, with the same key, gets readings for Nairobi. So that is where it runs. The pipeline has been proven end to end on a neighbouring city, and the Dar es Salaam point list is ready for the day a source exists.

Switching back is one setting: the city name.

What would unlock Dar es Salaam

  • Another provider

    The collector is the seam: a new one only has to map its answer onto the same row. A check-coverage command probes a provider before anything is built on it.

  • Daladala GPS traces

    The city's minibuses, each painted with a colour band for its route, drive the main corridors all day. Position traces from a fleet would give speeds with no outside provider at all.

  • Academic counts

    Published counts from the university and development agencies could seed a baseline to check any live source against.
